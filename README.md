# Rohith Senthil Kumar — Full Stack Developer & Designer Portfolio

Personal portfolio website for **Rohith Senthil Kumar**, student at **National Institute of Technology, Tiruchirappalli (NITT)**, featuring an interactive **Zero Vortex 3D WebGL background** in cosmic purple and the kinetic typography design patterns of [experiments.p5aholic.me](https://experiments.p5aholic.me/).

---

## ⚡ Quick Start

### Run Development Server
```bash
npm run dev
```
Open **[http://localhost:5173](http://localhost:5173)** in your browser.

### Build for Production
```bash
npm run build
```
